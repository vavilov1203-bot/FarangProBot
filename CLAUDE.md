# Правила работы над FarangProBot

- Всегда отвечай Дмитрию на русском языке.
- Дмитрий не программист, поэтому объясняй действия простым языком.
- Перед изменением кода сначала показывай краткий план.
- Делай изменения небольшими этапами.
- Не изменяй рабочую ветку main напрямую.
- Не выполняй git push, merge, force push или удаление веток без отдельного разрешения.
- Не удаляй файлы без отдельного разрешения.
- Не изменяй секреты, токены и переменные Render.
- Никогда не записывай токены, API-ключи или пароли в код.
- Не показывай секретные значения полностью.
- Не изменяй файл базы данных вручную.
- После каждого изменения проверяй синтаксис и работу затронутой части.
- Не переделывай архитектуру целиком без необходимости.
- Сохраняй текущую работающую логику бота.
- Для информации о визах, законах, налогах, медицине и официальных процедурах используй в первую очередь официальные источники.
- Не добавляй неподтверждённые сведения.
- Для изменяемой информации указывай источник и дату проверки.
- Если источники противоречат друг другу, сообщай об этом.
- Перед добавлением большого объёма контента сначала показывай структуру и план.
